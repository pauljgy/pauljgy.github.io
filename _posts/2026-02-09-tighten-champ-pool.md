Writing down some thoughts on champ pool/strategies.

Champ pool should be:
- **Main: Mundo, Cho, Jax**
- **Counter: Darius, Gragas**

Notes on each champion:
1) **Mundo**
- Only goal is to get to heartsteel + warmogs as fast as possible.
- Play safe and only harass if the Q is free. O.w., prioritize farm in lane.
- Very bad to lane against **Gwen, Vayne, Irelia, Yone**, across all stages of the game. Gwen passive/bork on other champions is a hard counter, need to respect it.

2) **Cho**
- Almost always picking this because team needs CC/frontline.
- Build full tank always.
	- First buy: Wardens mail/negatron
	- First item: Heartsteel
	- Second: Frozen heart/kaenic
	- Third: Default to jaksho, but adjust for visage/randuins
	- Later: Riftmaker/others
- Runes:
	- if enemy is ranged -> comet
	- if enemy is volatile -> hob
	- if enemy is sleeper tank -> grasp

3) **Jax**
- Don't shy away from volatile matchups; we are at this rank for a reason and the enemies are not going to be mechanical gods.
- Figure out long/short trades
- If short, take grasp + rush sheen
- If long and volatile, take LT + ignite and rush phage to run them down.

4) **Darius**
- Mainly play this against Garen or lots of melee champs

5) **Gragas**
- Play if team needs AP.
